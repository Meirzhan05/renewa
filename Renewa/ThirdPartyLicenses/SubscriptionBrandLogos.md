## Logo.dev fallback

When configured with a user-provided publishable key, Renewa requests unknown service logos by company name from [Logo.dev](https://logo.dev). No secret Logo.dev key is included in the app. Logo.dev's free commercial tier requires attribution, which Renewa displays as a link in Profile while the fallback is enabled.
